
# Daily Logger (دیلی لاگر)

یک سیستم مدیریت و ثبت فعالیت‌های روزانه هوشمند که با **Django** و **Bootstrap** توسعه داده شده است.

---

## Features

-  **احراز هویت کاربران:** سیستم ثبت‌نام، ورود و خروج امن (`registration` & `users`)
-  **مدیریت فعالیت‌ها:** قابلیت افزودن، ویرایش، حذف و مشاهده تاریخچه لاگ‌ها (`logs`)
-  **داشبورد تحلیلی:** نمایش آمار فعالیت‌ها و نمودارهای وضعیت برنامه‌ها
-  **تعاملات زنده:** استفاده از AJAX برای تغییر وضعیت کارها بدون رفرش صفحه
-  **امنیت:** مدیریت متغیرهای محیطی با `python-dotenv` جهت حفاظت از کلیدها

---

## تکنولوژی‌های استفاده‌شده

- **Backend:** Python, Django
- **Frontend:** HTML5, CSS3, JavaScript, jQuery, Bootstrap, FontAwesome
- **Database:** SQLite (قابل ارتقا به PostgreSQL)
